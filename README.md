# PESADILLA

Shooter gratis para navegador, con mandos para móvil y para teclado y ratón, ambientado en un pueblo
español de pesadilla. **Adaptación hecha por Novak M.**

**Jugar:** https://zarkominic.github.io/pesadilla/
